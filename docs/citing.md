# Citing

If you use res-asset-kpi in work you publish, please cite the software through its Zenodo DOI:
[10.5281/zenodo.23742958](https://doi.org/10.5281/zenodo.23742958) points to all versions, and each release has
its own DOI (0.1.0: [10.5281/zenodo.23742959](https://doi.org/10.5281/zenodo.23742959)). The repository also
carries a `CITATION.cff` file (GitHub shows a "Cite this repository" button).

```bibtex
@software{waleszczynski_res_asset_kpi,
  author  = {Waleszczyński, Konrad},
  title   = {res-asset-kpi: key performance indicators for operating PV, wind and battery assets},
  version = {0.1.0},
  doi     = {10.5281/zenodo.23742958},
  year    = {2026},
  url     = {https://github.com/kwwaleszczynski-del/res-asset-kpi},
  license = {MIT}
}
```

Please also cite the methods you rely on (listed at the end of each [methods](methods/pv.md) page) and the data
sets you analyse.
